🩺 Schedula Backend v2

Intelligent Healthcare Appointment Scheduling Platform

Schedula Backend v2 is a healthcare appointment scheduling system built using Node.js, Express.js, MongoDB, JWT Authentication, and advanced scheduling features.

The platform enables secure user authentication, appointment booking, appointment management, advanced scheduling, and appointment rescheduling with proper validations.

📌 Project Overview

Schedula simplifies healthcare appointment management by providing a scalable backend system for patients and healthcare providers.

The system supports:

- User Authentication
- Appointment Scheduling
- Appointment Management
- Availability Management
- Conflict Detection
- Advanced Scheduling
- Appointment Rescheduling
- Role-Based Access Control
